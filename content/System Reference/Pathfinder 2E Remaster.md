## 🎲 System Overview

The **Pathfinder Second Edition Remaster** project represents a complete modernization and streamlining of the core tactical fantasy tabletop engine. Designed to completely sever ties with legacy open-game licenses, it introduces an unchained, highly customizable rule set across fresh core volumes like the _Player Core_ and _GM Core_.
