🛠️Overview
Pathfinder Dashboard is a highly optimized, browser-based combat tracker, monster browser, and encounter builder tailored specifically for the Pathfinder 2e ruleset. Built as a lightweight and responsive web utility, it streamlines initiative tracking, player character metrics, and condition management on the fly. For a deep, multi-timeline sandbox vault, it functions as an essential companion tool for the Game Master to deploy live-updating monster stat blocks, track complex turn orders, and balance encounter XP scaling instantly without slowing down table momentum.
